## 单入口问答合同

`POST /wp-json/npcink-toolbox/v1/smart-ask`，`cap.toolbox.admin`，默认
`manage_options`，沿用 cookie + REST nonce。回调本身也检查管理员权限。
新增接口不放宽权限；旧五类独立接口保持兼容。

JSON body 只接受：

- `question`: 非空字符串，sanitize 后最多 2000 UTF-8 字节，以遵守已有摘要接口的
  最严界限；不静默截断。
- `source_hint`: 可选，空或既有五类内部来源之一，仅表示进入位置。
  旧 `ask_pack` 链接映射到 hint；编辑后的问题优先，hint 不是授权或强制选源。

一次问题最多：

1. 一次 Cloud 资料选择判断：只送问题与位置 hint，不收集/发送站点数据。
   复用 `hosted_ai_content_support.v1` / `text.ai`，15 秒、600 输出 tokens，
   `pii` + `no_store`，零 retention、retry、fallback。不新增模型/供应商配置。
2. 严格校验 action/source/message。清楚的请求只分发一个现有问答能力；
   跨范围且单一既有来源不能覆盖、含糊或缺少对象的问题先澄清，不全量取包。
   选择器不能产生任意 endpoint、写动作、第二注册表或暂停功能恢复。
3. 普通建议或不具备流量/排名/实测数据的问题可返回简短一般性指引，明确尚未检查
   本站。不得把一般知识当成本站证据；不承诺测速、修改、发布或调度。

返回沿用已选接口的回答、引用和验证边界，增加 `answer_basis`：
`site_summary` / `public_content` / `clarification` / `general_guidance`。
界面明确区分摘要、原文引用、澄清和未检查本站的一般建议。
澄清要求用户在原问题中补充信息；不新增完整聊天历史或持久会话。

`run_id` 是最终调用编号；已分发时另附 `decision_run_id`，仅在支持详情显示。
上游错误只保留安全状态和关联编号，不返回原始请求或运行明细。任一阶段失败即停止，
不猜测来源、不重试、不轮询。浏览器仍有 90 秒总等待和停止等待；停止不表示取消
已经发出的 Cloud 请求。

所有结果 `suggestion_only`、`direct_wordpress_write=false`、
`proposal_created=false`，HTTP `Cache-Control: no-store`。不会提交/批准 Core、
写入文章/媒体或新增后台任务。
