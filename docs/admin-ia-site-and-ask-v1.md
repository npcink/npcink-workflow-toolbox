## 产品意图（降门槛）

本系列（`#311`–`#321`）目标是**降低站长使用智能提问的门槛**：顶栏变少、稀疏散入口默认隐藏、开始页只留清晰下一步、检查结果一键带到提问。不改 pack REST / `suggestion_only` 边界；不把 Addon 控制面塞进 Toolbox。
